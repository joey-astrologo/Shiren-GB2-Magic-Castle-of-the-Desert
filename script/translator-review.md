# Translator spreadsheet

[`translator-review.tsv`](translator-review.tsv) is a single UTF-8, tab-separated
sheet containing all 6,695 extracted records. Its English is verified byte for byte
against a validated build of the current `script/en/` translation, including inserted
line breaks, control codes and byte-specific glyph tokens. The original `script.tsv`
is kept separately.

| Column | Meaning |
|---|---|
| `id` | Stable original record ID, in decimal-bank:`$hex-address` form. Preserve it when sorting or returning edits. |
| `loc` | That record's relocated address in the English build, using the same notation. It can change after rebuilding; use `id` to identify a record. |
| `bytes` | Inserted record length in bytes, including control arguments but excluding the final `FF` terminator. This is a measurement, not an editing limit. |
| `jp` | Original Japanese/source text with the project's readable control tokens. |
| `en` | Current inserted text. Preserve this baseline when proposing changes. `<empty>` represents a zero-byte record, not visible text. |
| `edited_en` | Blank column for proposed English changes. Leave blank for no proposed change. |

The full dump includes internal and fixed records. Where the build retains native
bytes, `en` shows that native text rather than an invented translation. These rows
are included for completeness; the [workbench coverage](../docs/translation-tool/coverage.html)
identifies surfaces that remain references. Runtime placeholders remain tokens;
text generated by game code and text drawn as graphics are outside this script dump.

Import the file into your spreadsheet as **UTF-8**, with **Tab** as the separator.
Keep `id`, `loc`, `jp`, `en` and `edited_en` as text, and disable automatic conversion
to numbers, dates or formulas so digit strings and punctuation remain unchanged.
Edit only `edited_en`. Keep the controls needed by the entry; consult the
[GB2 control reference](https://joey-astrologo.github.io/Shiren-GB2-Magic-Castle-of-the-Desert/translation-tool/controls/).

Hex payloads and pointer references are omitted because the stable ID identifies
the source record. The original extraction retains those details for validation.
One row may serve several places in the game, so a proposed edit applies to all
uses of that record.

This sheet is a review format. It is not accepted directly by the existing browser
changes importer. Returned edits need to be converted and validated through the
appropriate workbench/draft owners before insertion. Keep the unchanged `id`, `jp`
and `en` columns so that review can detect an outdated baseline.

## Generate a fresh sheet

From the repository root, with the normal build dependencies and your original ROM:

```sh
ROM="Fushigi no Dungeon - Fuurai no Shiren GB2 - Sabaku no Majou (Japan).gbc"
python3 tools/export_script_sheet.py "$ROM" script/en --out script/translator-review.tsv
```

The exporter builds and validates in memory without writing a ROM or changing the
translation. It checks all exported text against the inserted bytes and leaves
`edited_en` blank. It refuses to overwrite an existing file; choose a new filename
such as `script/translator-review-v2.tsv` for a later snapshot. The shared
`script/translator-review.tsv` can be committed to Git; additional review snapshots
remain ignored.
