# Blank Scroll input list

Choose **Write** on a Blank Scroll and enter the text in the **Type this** column
exactly. Do not enter the word `Scroll`. Capitalization matters, and the resulting
Scroll must already have been read and recorded in the current save's notebook.

created with **Write**. For the matching rules and implementation details, see
[Blank Scroll writing system](BLANK_SCROLL.md).
