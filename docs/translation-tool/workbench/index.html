EDITING GUIDE

Editing rules

Each entry lists its own GB2 surface and controls. Prose wraps at word spaces. Other subjects retain explicit line breaks; item messages without conditional checkpoints use the project's greedy wrapper.

  • Use the installed English glyphs and straight quotes. Enter inserts <br>; Ctrl/Cmd+Enter inserts <page><box>.
  • Keep the listed runtime substitutions, timing effects, page boundaries and native selectors. <page> waits without resetting the cursor. <cF3> marks a conditional rollback point.
  • Names update shared runtime widths and terminology checks. Use Needs attention to find affected entries across all subjects. Related names may need to change together.
  • Descriptions retain item stat headers. Help retains its source line budget and critical controls. Notebook descriptions keep their exact line count and are checked with the monster name.
  • Positioned labels use the actual text interior and cursor limits. Reference entries explain why a script-only edit is unavailable.
  • Both preview fonts use the same widths. The preview shows text geometry; runtime spans reserve measured widths and appear shaded.

All workbenches share one draft. Invalid drafts are saved and can be backed up, but any invalid entry or shared dependency blocks the changes download. Import the downloaded TSV with tools/workbench_web.py import ROM changes.tsv, then add --apply after reviewing the validation and diff.
