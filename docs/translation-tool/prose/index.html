EDITING GUIDE

Prose editing rules

GB2 dialogue uses three physical lines per box. Text wraps at word spaces using the installed Thin Pixel-7 font: below 144 composer pixels and at most 144 renderer pixels. There is no character-count limit for a line.

  • <br> advances a line immediately. Enter inserts it.
  • <page> waits for input and keeps the pen and line cursor. Use <page><box> to wait and start a new box. Ctrl/Cmd+Enter inserts both.
  • Keep source page/box boundaries in order. Keep the break after a source <page><br>, or replace it with a box reset.
  • Keep runtime substitutions and timing/effect controls with their exact arguments and counts. Keep <cF8> selector runs in order and unchanged; keep at least one required <cF3>.
  • Use Name: dialogue speaker labels, straight ASCII quotes, and the listed project terms. Repeat the speaker label when needed after a new box.
  • Keep the exact four-letter Big Moai story codes when they appear in an entry.
  • The last row must keep every 8px glyph cell inside the box. A page marker needs 9px at the pen, so a wait must begin at 135px or earlier.
  • Runtime names and values reserve the measured project maximum. Player names allow six characters; the checker retains a conservative 49px reservation.

Downloads contain only changed, validated entries with their project baselines. Import them with the project's prose importer for the full owner and lint checks, then build and test in game. The preview cannot judge translation accuracy, event timing or every runtime replacement.

Scenes follow the project map. Branches and optional events are grouped by phase, not forced into a single timeline. Thin Pixel-7 by Sizenko Alexander (Style-7), adapted to the Game Boy cell.
